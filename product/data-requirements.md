# Data requirements

| Class | Examples | Status |
|-------|----------|--------|
| Public official | MoFA production, trade stats, GCX bulletins | Used in desk research; not piped |
| Multilateral / attaché | USDA GAIN, WITS | Used in desk research |
| Processor private | Historical purchases, specs, suppliers | Not collected — needs consent |
| Aggregator / PO private | Lots, member forecasts | Not collected — needs consent |
| Geo / weather | District boundaries, rainfall | Only if workflow justifies |
| Documents | Standards, policy PDFs | Licence-aware curation TBD |

## Minimum pilot set (only if hypothesis survives discovery)

One processor’s multi-season purchases (possibly anonymised); district production estimates; a price panel; quality specs; an aggregator directory for one geography.

Logical fields: [data/schema.md](../data/schema.md).
