# Validation metrics

Pre-register numeric thresholds before looking at outcomes.

| Gate | Metric | Advance if | Stop / pivot if |
|------|--------|------------|-----------------|
| Problem | Share of processors ranking find/confirm supply in time as top-3 constraint | ≥ pre-registered fraction | Capital/tariff/quality/export dominate exclusively |
| Data | Consented usable purchase or lot data | ≥1 crusher geography + supply-side partner | No data path |
| Behaviour | Shadow/pilot changes plans or search time | Pre-registered effect | No behavioural change |
| Trust | Hallucination/unsupported-number rate on gold tasks (if RAG built) | Below threshold | Persistent fabrication of tonnes/prices |
| Adoption | Active use or willingness-to-pay after fair pilot | Above floor | Shelfware / refusal |
| Integrity | Public claims still match evidence labels | Audit pass | Any false customer/revenue/performance claim |
