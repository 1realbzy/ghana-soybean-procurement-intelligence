# Validation metrics

| Gate | Metric | Advance if | Kill / pivot if |
|------|--------|------------|-----------------|
| Problem | Share of processors rating “finding suitable local beans in time” as top-3 constraint | ≥ pre-registered fraction | Capital/tariff/quality dominate exclusively |
| Data | Pilot partner shares usable historical purchases | ≥1 crusher + ≥1 aggregator geography | No data access path |
| RAG | Hallucination rate on gold questions | Below pre-set threshold | Persistent fabrication of tonnes/prices |
| Forecast | MAE vs naive baseline | Strictly better | No lift after honest tuning |
| Adoption | Weekly active use in pilot | Above floor for 4–6 weeks | Shelfware |
| Integrity | All public claims still match labels | Audit pass | Any fake customer/revenue/performance claim |

Pre-register numeric thresholds in a validation protocol **before** looking at pilot outcomes.
