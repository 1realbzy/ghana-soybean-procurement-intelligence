# Retrieval architecture

**Hypothesis:** if processors need answers grounded in mixed documents and tables, a retrieval-augmented interface with hard refusal on unsupported numbers is worth building.

## Proposed behaviour

Every numeric claim cited or marked as a model estimate from a named classical method. Low retrieval coverage → explicit gap. UI badges for source vs estimate vs unknown.

## Status

Hypothesis and design notes only. No vector index, corpus, or eval set in this repository.
